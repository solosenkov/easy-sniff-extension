# Changelog

## 3.7.0

- Add opt-in full HTTP capture to Bug Replay: raw headers, Cookie/Set-Cookie, tokens, available bodies, timing, and cURL.
- Inspect request details in the extension and the exported offline HTML report.
- Store HTTP details separately in IndexedDB and show missing/truncated body information.

## 3.6.0

- Add Bug Replay: tab video with network, console, WebSocket metadata, error markers, and QA markers on a shared timeline.
- Export an offline ZIP containing `report.html`, `video.webm`, and `session.json`.
- Replace the experimental Time Machine feature with Bug Replay.

## 3.5.0

- API client, filtered network capture, traffic overrides, WebSocket scenarios, and decoders.
- Bring-your-own-model AI assistant with editable HTTP and WebSocket proposals.
- English and Russian interfaces.

## Public launch preparation

- Add MIT licensing, a runnable public test suite, CI, contribution guidance, and issue templates.
- Refresh installation instructions, privacy documentation, and examples.
